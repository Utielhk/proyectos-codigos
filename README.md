# 📅 Contador de Domingos (Siglo XX)

Un script sencillo en Python que calcula cuántos meses comenzaron en domingo durante el siglo XX (desde el 1 de enero de 1900 hasta el 31 de diciembre de 2000). 

Este es un ejercicio clásico de lógica y fechas en programación (inspirado en el Problema 19 de Project Euler).

## 🚀 Requisitos

- **Python 3.x** instalado en tu computadora.
- No requiere librerías externas. Utiliza el módulo estándar `datetime` de Python.

## 🛠️ Cómo ejecutarlo

1. Guarda el código en un archivo llamado `contar_domingos.py`.
2. Abre tu terminal o línea de comandos.
3. Navega hasta la carpeta donde guardaste el archivo.
4. Ejecuta el siguiente comando:

   ```bash
   python contar_domingos.py
